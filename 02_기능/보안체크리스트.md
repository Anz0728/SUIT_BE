# MVP 보안 체크리스트

## 배포 전 필수

- [ ] GitHub 저장소를 Private으로 유지
- [ ] `.env`, DB URL, JWT secret이 Git 기록에 없는지 검사
- [ ] 운영용 JWT secret을 32자 이상 무작위 값으로 교체
- [ ] bootstrap token을 JWT secret과 다른 32자 이상 무작위 값으로 설정
- [ ] 첫 관리자 생성 직후 `SUIT_BOOTSTRAP_ENABLED=false`로 재배포
- [ ] PostgreSQL TLS 연결 사용
- [ ] API 도메인에 HTTPS 적용
- [ ] CORS를 실제 프론트 도메인만 허용
- [ ] `SUIT_ALLOWED_HOSTS`를 실제 API 도메인만 허용
- [ ] 첫 관리자 bootstrap 완료 후 외부 접근 차단
- [ ] 관리자 계정 MFA 적용 가능한 인증 공급자로 전환 계획 수립
- [ ] 브라우저가 access token을 localStorage·sessionStorage에 저장하지 않는지 확인
- [ ] DB 자동 백업과 복구 테스트
- [ ] 로그에서 대화 내용과 토큰 제거 확인
- [ ] 만료·삭제된 대화가 백업 및 객체 저장소에서도 제거되는 정책 확인
- [ ] GitHub Actions의 test, Ruff, Bandit, pip-audit, secret 검사 통과 확인
- [ ] Dependabot 보안 업데이트 PR 검토 담당자 지정

## AI 연결 전 필수

- [ ] 원본 영상·음성 기본 미저장
- [ ] 모델 공급자와 개인정보 처리·국외 이전 범위 확인
- [ ] 파일 형식·실제 MIME·크기·재생시간 검증
- [ ] 기관·사용자·IP별 요청량과 동시 처리 제한
- [ ] 추론 timeout과 circuit breaker
- [ ] 낮은 신뢰도 결과는 자동 전달하지 않고 사용자 확인
- [ ] 모델 버전과 신뢰도만 기록하고 원문 로그 최소화
- [ ] 학습 활용 동의를 서비스 이용 동의와 분리
