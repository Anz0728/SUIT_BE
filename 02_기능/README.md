# 02. MVP 기능

## 구현 완료

### 기관과 인증

- DB 단일 행 제약으로 동시 요청에도 첫 기관·관리자 1회만 생성
- 초기 관리자 API 기본 비활성화 및 별도 초기화 토큰
- Argon2 비밀번호 해시
- 취약한 비밀번호 차단 및 해시 정책 자동 갱신
- 만료시간이 있는 JWT access token
- JWT `jti`·인증 버전 검증으로 권한 변경 시 기존 토큰 즉시 차단
- 관리자·직원 역할 분리
- 비활성 계정 차단
- 기관 간 데이터 격리

### 표현 관리

- 병원 접수와 공공기관 민원 기본 표현
- 프론트 확장용 학교·복지기관 상황 유지
- 기관 전용 표현 추가·수정·삭제
- 공통 표현 보호
- 입력 길이와 중복 검증

### 대화

- 상황별 대화 생성
- 수어·음성·직접 입력 메시지
- 번역문과 신뢰도 저장
- 확인 후 문장 수정 표시
- 대화 목록·상세·즐겨찾기
- `저장 안 함`, 24시간, 7일, 계속 보관
- 생성자 또는 기관 관리자만 수정·삭제

### 보안·운영 기본값

- 정확한 Origin만 허용하는 CORS
- Host allowlist
- 요청 본문 크기 제한
- `Content-Length`가 없는 스트리밍 요청까지 본문 크기 제한
- 로그인·초기화·AI·관리자 API별 rate limit
- 요청 ID
- 보안 응답 헤더
- 관리자 변경 감사 로그
- 만료된 대화 자동 정리
- 원본 영상·음성 미저장
- 운영 환경의 약한 JWT 비밀키 실행 차단
- 운영 환경에서 SQLite·HTTP CORS·로컬 Host·과도한 토큰 수명 실행 차단
- 비루트·권한 제거·읽기 전용 Docker 실행
- GitHub Actions 보안 검사와 Dependabot

## 이번 MVP에서 의도적으로 제외

- 실제 수어 인식 모델
- 실제 STT·자동 번역 공급자
- 원본 영상·음성 업로드 및 보관
- 환자 회원가입과 환자 식별정보
- 진단·처방·복지 자격 자동 판단
- 결제
- 모델 학습 데이터 수집

이 기능들은 외부 공급자, 개인정보 동의, 비용 제한, 정확도 평가가 확정된 뒤 별도 단계로 구현해야 합니다.
